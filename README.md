### Featured project

#### [RIFDAN | Donation Analytics & Decision Support](https://github.com/ziyadell/RIFDAN-Data-Analytics)

An analytics project exploring **40,930 donation transactions** from a historical sample of Saudi open data. The project brings together data cleaning, exploratory analysis, donor segmentation, an interactive Arabic dashboard, and an executive report, with clear privacy and data limitations.
